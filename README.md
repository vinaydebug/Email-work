# Email Work — Live Email Samples

A curated collection of real-world email templates and samples covering various professional communication scenarios.

## What's Inside

This repository contains live email samples organized by use case — useful as reference, inspiration, or starting points for your own email writing.

## Use Cases

- Product, brand emails for product launch.
- Response templates

## How to Use

Browse the files, copy any sample, and adapt it to your context. Each file is named to reflect its purpose.

## Contributing

Have a great email template? Open a PR — keep samples generic enough to be reusable.
